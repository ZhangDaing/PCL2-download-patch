# PCL2 MC 下载修复补丁

修复 Plain Craft Launcher 2 **2.99.0.0** 中与 MC 下载相关功能失效的问题。

> 本项目绝大部分代码与文档由 AI 编码代理生成，详见文末声明。

---

## 修复内容

| 功能 | 修复前 | 修复后 |
|---|---|---|
| 下载原版游戏 | 版本列表加载不出来 | ✅ 正常 |
| 下载整合包 | 下载成功但装不上 | ✅ 正常 |
| 拖入整合包安装 | 无反应 | ✅ 正常 |
| 版本设置「修改 MC 版本」 | 卡片被隐藏 | ✅ 正常 |
| 资源页整合包「安装」按钮 | 只能「保存」不能「安装」 | ✅ 正常 |

---

## 使用方法

1. **完全关闭 PCL**
2. 下载本仓库，解压
3. 双击 `apply.bat`

如果自动找不到 PCL，手动指定路径：

```
apply.bat "C:\你的PCL目录\Plain Craft Launcher 2.exe"
```

然后启动 PCL，下载页应该能看到原版版本列表了。

---

## 还原

双击 `restore.bat`，或手动把 `Plain Craft Launcher 2.exe.orig` 改回原名。

---

## 查看补丁状态

```
bin\Verify.exe "C:\你的PCL目录\Plain Craft Launcher 2.exe"
```

- `PASS` —— 补丁生效中
- `FAIL` —— 未打补丁

---

## 注意事项

**PCL 更新后补丁会失效。** 更新是整包替换 exe，任何修改都会丢失，
更新后重新运行一次 `apply.bat` 即可。

补丁器会先备份原文件（`.orig`），失败时不会改动原文件。
如果 PCL 结构变化导致补丁器无法识别，它会报错退出而不是写坏文件。

杀毒软件可能对修改过的 exe 报警。
